# 지역 데이터랩 웹앱 기본 프레임

전국 행정구역의 세대 현황을 보여주는 웹, 스마트폰 화면이다. 밝은 바탕 위에 지역 검색, 핵심 숫자 3개, 차트 3개가 세로로 놓인다. 데이터 흐름: 통계청 인구, 가구 및 주택 CSV → `public/households.csv` → 이 웹앱. 이 문서 하나에 모든 규칙이 있다. 아래 Setup, Tokens, styles, 컴포넌트 섹션을 모두 따른다.

## 반드시 지킬 시각 규칙

1. **텍스트는 페이지 바탕(`--surface`) 위에 바로 놓는다.** 배경색 있는 사각 박스 위에 글자를 올리는 건 버튼과 핵심 숫자 띠만 허용. 카드 UI를 만들지 않는다.
2. **사각 프레임에 테두리 금지.** border, outline 장식, ring 클래스 모두. (키보드 포커스 링만 예외)
3. **사각 프레임에 라운드 금지.** 버튼, 셀렉트, 입력창, 막대그래프 포함 모든 사각 요소 `border-radius: 0` (rounded-* 클래스 금지). 원형 요소(차트 점, 상태 점)만 원.
4. **무의미한 소제목 금지.** 제목 위 작은 영문 라벨("HOUSEHOLD TREND" 같은), 번호(01, 02), 알약 라벨을 달지 않는다. 차트 제목은 차트가 무엇을 보여주는지만 쓴다("세대수 상위 10개 시군구"). 컨트롤 이름은 무엇을 조작하는지만 쓴다("지역 찾기", "지역 선택"). 섹션 이름은 `aria-label`로.
5. **중점(·) 금지.** "시·군·구"는 "시군구"로 쓴다. 나열은 쉼표나 줄바꿈으로.
6. **자간, 행간은 폰트 기본값.** `letter-spacing`, `line-height`를 지정하지 않는다 (tracking-*, leading-* 클래스 금지). 대문자 라벨(uppercase) 금지.
7. 색, 크기, 간격은 Tokens의 CSS 변수만. Tailwind 기본 팔레트나 임의 hex 금지.
8. 구분은 여백으로. 구분선, 그림자, 그라데이션, 장식 원, 이모지 금지. `--line`은 차트 그리드와 막대 트랙에만.

## 반드시 지킬 동작 규칙

1. 상태(불러오는 중, 오류, 검색 결과 없음)는 항상 **글자로** 표시한다. 색만으로 구분 금지. 차트 계열(시, 군, 구)도 범례 글자로 함께 표시한다.
2. 버튼, 셀렉트, 검색 결과 항목 터치 영역 최소 44px. 스마트폰(375px)에서 가로 스크롤 금지.
3. 화면은 상태 3개(`regions`, `selected`, `query`)에서만 그린다.
4. 데이터는 `public/households.csv` 하나에서만 읽는다. 숫자를 코드에 직접 쓰지 않는다. 숫자는 천 단위 쉼표로 표시한다.
5. 바탕은 밝은색 한 테마. 텍스트 대비 4.5:1 이상.

## 제품 슬롯 (학생이 채우는 칸)

제품 이름, 컨셉, 설명은 `src/product.ts`의 `PRODUCT` 객체 한 곳에서만 정의하고 화면은 거기서 읽는다. 비어 있으면 `[제품 이름]` 같은 자리표시를 `--ink-muted`로 보여준다.

| 슬롯 | 위치 |
| --- | --- |
| 제품 이름 | `PRODUCT.name`. 지역 데이터랩 |
| 제품 컨셉 (한 줄) | `PRODUCT.concept`. 숫자로 읽는 우리 지역의 변화 |
| 제품 설명 (2~3문장) | `PRODUCT.description`. 전국 행정구역의 세대 현황을 한눈에 살펴보세요. 지역별 규모와 분포를 쉽고 빠르게 비교할 수 있습니다. |
| 데이터 출처 | `PRODUCT.source`. 통계청 2025 인구, 가구 및 주택 |
| 메인 컬러 | globals.css의 `--brand`, `--on-brand`. 기본값 블루 |
| 폰트 | globals.css의 `--font-sans`(메인, 기본값 Pretendard), `--font-display`(서브, 기본값 Pretendard 굵게). 서브는 제품 이름과 큰 숫자에만 |

## 기능

| 기능 | 컴포넌트 | 데이터 |
| --- | --- | --- |
| 제품 정보 | ProductHeader | `PRODUCT` |
| 지역 검색 (최대 8개 결과, 누르면 선택) | RegionSearch | `query`, `regions` |
| 기준 연도, 전국 총 세대수, 분석 시군구 수 | StatSummary | `regions` |
| 선택 지역 세대 추이, 지역 선택 | HouseholdTrend | `selected`, `regions` |
| 세대수 상위 10개 시군구 막대 | RegionRanking | 시군구 세대수 정렬 |
| 시, 군, 구 유형별 인구 0~1 정규화 선 | NormalizedChart | 시군구 인구 |
| 반응형 | AppShell | 768px 기준. 웹은 상단 2열(소개, 검색), 스마트폰은 1열 |

"지역 찾기"는 검색어로 지역 이름을 걸러 보여주는 동작이다. 결과가 없으면 "검색 결과가 없습니다"를 글자로 보여준다. 단일 연도 자료일 때 추이 차트는 점 하나와 안내 문장으로 보여주고, 연도 데이터가 늘면 선으로 확장된다.

## 응용 범위

- 바꿔도 됨: 제품 슬롯, 메인 컬러, 순위 개수, 검색 결과 개수, CSV 파일(같은 열 이름이면), 연도 추가, 섹션 추가.
- 바꾸면 안 됨: 위 시각 규칙과 동작 규칙, 상태 구조, CSV 열 이름("총인구", "가구_계").
